# Treinadora Metabólica GeekSTEAM

Site estático para GitHub Pages com 1, 2 ou 3 ciclos, áudio PT-BR e suporte PWA.

Publicar arquivos na raiz do branch main e habilitar Pages em Settings > Pages > Deploy from a branch > main / (root).

A aplicação não coleta dados pessoais, não usa backend e funciona offline depois que os arquivos são armazenados pelo service worker.
